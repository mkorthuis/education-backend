# Shared Topics for Town Research

The topic slugs every town's research uses, so facts from different towns sit under the same topics, each with its own `place`. Use these exact slugs, kinds and question types. The title and description are the topic's own when the library is loaded; each file's heading for the topic is kept with its facts. The descriptions are what the Ask's catalog will show, so keep them general, never naming a town.

If no topic fits, propose a new one in your file's summary. Don't invent a town-specific slug. New topics are added here after review.
